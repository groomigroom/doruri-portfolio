HTML의 <button> 태그에서 data-board-id(또는 data-boardid)와 같은 속성은 개발자가 임의의 데이터를 HTML 요소에 저장해 두기 위해 사용하는 사용자 정의 데이터 속성(Custom Data Attribute)인 data-* 속성입니다. [1, 2] 
## 1. 핵심 의미

* data-로 시작하는 속성: HTML5 표준으로, 사용자가 임의의 이름을 붙여 데이터를 저장할 수 있게 해줍니다. 브라우저는 이 속성을 특별히 해석하지 않고 그대로 유지합니다. [1] 
* board-id의 의미: 게시판(Board) 시스템 등에서 특정 게시글의 고유 번호(ID)를 의미합니다. 예를 들어 특정 게시글을 삭제하거나 수정, 상세 조회하는 버튼에 이 속성을 달아둡니다.

------------------------------
## 2. 사용 예시

<button type="button" class="btn-delete" data-board-id="105">삭제하기</button>

위와 같이 작성하면, 105번 게시글을 지우기 위한 버튼임을 HTML 상에서 명확히 나타낼 수 있습니다.

좋아요 토글 시 프론트엔드(Fetch API)부터 백엔드(Spring Boot), 데이터베이스(SQL)까지 연결되는 전체 파이프라인 구현 방법입니다.
사용자가 버튼을 누르면 화면의 클래스가 바뀌고(Toggle), 그 상태에 따라 서버에 등록(INSERT) 또는 취소(DELETE) 요청을 보낸 뒤 DB를 업데이트하는 흐름입니다.

## 1. Front-end: HTML & JavaScript (Fetch API)
프론트엔드에서는 classList.contains()로 상태를 판별한 뒤, 각각 등록(POST) 또는 취소(DELETE) 요청을 보냅니다. 이때 어떤 게시글(또는 상품)의 좋아요인지 data-id 속성으로 넘겨줍니다.

<!-- HTML: 현재 로그인한 사용자가 1번, 게시글이 42번이라고 가정 -->
<button id="like-btn" class="like-button" data-board-id="42" data-user-id="1">
  <span class="icon">🖤</span> <span class="text">좋아요</span>
</button>

// '; 
  
  
        const likeBtn = document.getElementById('like-btn');

likeBtn.addEventListener('click', async () => {

    // 게시글 번호만 HTML에서 가져옴
    const boardId = likeBtn.dataset.boardId;

    const isLiked = likeBtn.classList.contains('active');

    const url = '/api/likes';
    const method = isLiked ? 'DELETE' : 'POST';

    try {
        const response = await fetch(url, {
            method: method,
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({
                boardId: boardId
            })
        });

        if (response.ok) {

            if (isLiked) {
                likeBtn.classList.remove('active');
                likeBtn.querySelector('.icon').textContent = '🖤';

                alert('좋아요를 취소했습니다.');

            } else {
                likeBtn.classList.add('active');
                likeBtn.querySelector('.icon').textContent = '❤️';

                alert('좋아요를 등록했습니다.');
            }

        } else {
            alert('처리에 실패했습니다.');
        }

    } catch (error) {
        console.error('네트워크 에러:', error);
    }
});

## 2. Back-end: Spring Boot (Controller & Service)
데이터를 주고받을 DTO를 정의하고, HTTP Method(@PostMapping, @DeleteMapping)에 따라 적절한 서비스 로직을 실행합니다.
## LikeDto.java (데이터 전달 객체)

public class LikeDto {
    private Long boardId;
    private Long userId;

    // Getter, Setter, Constructor 생략
}

## LikeController.java (컨트롤러)

@RestController
@RequestMapping("/api/likes")public class LikeController {

    @Autowired
    private LikeService likeService;

    // 좋아요 등록 (POST)
    @PostMapping
    public ResponseEntity<String> registerLike(@RequestBody LikeDto likeDto) {
        likeService.addLike(likeDto);
        return ResponseEntity.ok("Like added successfully");
    }

    // 좋아요 취소 (DELETE)
    @DeleteMapping
    public ResponseEntity<String> cancelLike(@RequestBody LikeDto likeDto) {
        likeService.removeLike(likeDto);
        return ResponseEntity.ok("Like removed successfully");
    }
}

## LikeService.java (서비스)

@Servicepublic class LikeService {

    @Autowired
    private LikeMapper likeMapper; // MyBatis 또는 JPA Repository 사용 가능

    public void addLike(LikeDto likeDto) {
        // 이미 좋아요를 누른 상태인지 검증 로직을 추가하면 더 안전합니다.
        likeMapper.insertLike(likeDto);
    }

    public void removeLike(LikeDto likeDto) {
        likeMapper.deleteLike(likeDto);
    }
}

## 3. Database: SQL (MyBatis XML 기준 예시)
데이터베이스 테이블은 보통 누가(user_id), 어떤 글에(board_id) 좋아요를 눌렀는지 복합키 형태로 관리합니다.
## 좋아요 테이블 구조 (DDL)

CREATE TABLE likes (
    board_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (board_id, user_id) -- 중복 등록 방지 복합키
);

## LikeMapper.xml (SQL 쿼리)

<!-- 좋아요 등록 (INSERT) -->
<insert id="insertLike" parameterType="LikeDto">
    INSERT INTO likes (board_id, user_id)
    VALUES (#{boardId}, #{userId})
</insert>
<!-- 좋아요 취소 (DELETE) -->
<delete id="deleteLike" parameterType="LikeDto">
    DELETE FROM likes 
    WHERE board_id = #{boardId} AND user_id = #{userId}
</delete>
