네. 지금 구조에서는 **`likeLinkCount`가 안 바뀌는 것이 정상**입니다.

 핵심 원인은 **Thymeleaf와 JavaScript의 실행 시점이 다르기 때문**입니다.

 현재 흐름을 보면:

```
서버
 ↓
SongMainService.getLikeLinkCount()
 ↓
Thymeleaf가 ${likeLinkCount}를 HTML로 변환
 ↓
브라우저에 "3개" 출력
 ↓
JavaScript로 좋아요 POST/DELETE
 ↓
DB는 4개 또는 2개로 변경
```

 여기까지는 되지만, **DB가 바뀌었다고 Thymeleaf가 다시 실행되지는 않습니다.**

 따라서:

```
<h2 th:text="${likeLinkCount} + '개'">
```

 이 값은 페이지를 새로고침하기 전까지 그대로입니다.

---

 ## 가장 간단한 해결 방법

 AJAX 요청이 성공했을 때 **화면의 좋아요 숫자도 JavaScript로 직접 변경**하면 됩니다.

 현재:

```
<h2 class="song_main_h2" th:text="${likeLinkCount} + '개'">개수개</h2>
```

 에 id를 하나 줍니다.

```
<h2 id="like_count"
    class="song_main_h2"
    th:text="${likeLinkCount} + '개'">
    0개
</h2>
```

 그리고 JS에서 현재 숫자를 가져와서 `+1`, `-1` 하면 됩니다.

```
const like_btn = document.querySelector(".like_btn");
const like_count = document.querySelector("#like_count");

like_btn.addEventListener("click", async () => {

    const originalLink = like_btn.dataset.originalLink;
    const is_liked = like_btn.classList.contains("active");

    const url = "/like-link/toggle-like";
    const method = is_liked ? "DELETE" : "POST";

    try {
        const csrfToken =
            document.querySelector('meta[name="_csrf"]').content;

        const csrfHeader =
            document.querySelector('meta[name="_csrf_header"]').content;

        const response = await fetch(url, {
            method: method,
            headers: {
                "Content-Type": "application/json",
                [csrfHeader]: csrfToken
            },
            body: JSON.stringify({
                originalLink: originalLink
            })
        });

        if (response.ok) {

            // 현재 좋아요 개수 가져오기
            let count = parseInt(like_count.textContent);

            if (is_liked) {
                // 좋아요 취소
                count--;
                like_btn.classList.remove("active");
                like_btn.textContent = "좋아요";
            } else {
                // 좋아요 추가
                count++;
                like_btn.classList.add("active");
                like_btn.textContent = "좋아요함";
            }

            // 화면 숫자 변경
            like_count.textContent = count + "개";

        } else {
            alert("처리에 실패했습니다. HTTP 상태: " + response.status);
        }

    } catch (error) {
        console.error("네트워크 에러:", error);
    }
});
```

 이렇게 하면:

```
처음
좋아요 3개

↓ 좋아요 클릭

DB
3 → 4

화면
3개 → 4개
```

 그리고 다시 클릭하면:

```
DB
4 → 3

화면
4개 → 3개
```

 가 됩니다.

---

 # 그런데 더 좋은 방법이 있습니다

 현재 방식은:

```
count++;
count--;
```

 로 화면 숫자를 변경합니다.

 이 방식의 단점은 **DB의 실제 숫자와 화면 숫자가 달라질 가능성**이 있다는 것입니다.

 예를 들어 동시에 다른 사람이 좋아요를 누르면:

```
DB = 10개
내 화면 = 9개
```

 같은 상황이 생길 수 있습니다.

 그래서 저는 **Controller가 좋아요 처리 후 현재 좋아요 개수를 반환하도록 만드는 방법**을 추천합니다.

---

 ## 1\. Service에서 count를 가져옵니다

 현재 `SongMainService`에 이미:

```
public int getLikeLinkCount(String originalLink) {
    return likeLinkRepository.countByOriginalLink(originalLink);
}
```

 가 있습니다.

 그런데 `LikeLinkController`에서는 `SongMainService`를 사용하지 않고 있습니다.

 따라서 Controller에 추가합니다.

```
private final SongMainService songMainService;
```

 그러면:

```
@RequiredArgsConstructor
@Controller
@RequestMapping("/like-link")
public class LikeLinkController {

    private final LikeLinkService likeLinkService;
    private final SongMainService songMainService;

    ...
}
```

---

 ## 2\. POST 후 현재 좋아요 개수를 반환

```
@PostMapping("/toggle-like")
public ResponseEntity<?> addLike(
        @RequestBody LikeRequest request,
        Principal principal) {

    if (principal == null) {
        return ResponseEntity.status(HttpStatus.UNAUTHORIZED)
                .body("로그인이 필요합니다.");
    }

    String userId = principal.getName();

    likeLinkService.addLike(
            request.getOriginalLink(),
            userId
    );

    int likeCount =
            songMainService.getLikeLinkCount(
                    request.getOriginalLink()
            );

    return ResponseEntity.ok(likeCount);
}
```

 DELETE도 동일하게:

```
@DeleteMapping("/toggle-like")
public ResponseEntity<?> deleteLike(
        @RequestBody LikeRequest request,
        Principal principal) {

    if (principal == null) {
        return ResponseEntity.status(HttpStatus.UNAUTHORIZED)
                .body("로그인이 필요합니다.");
    }

    String userId = principal.getName();

    likeLinkService.deleteLike(
            request.getOriginalLink(),
            userId
    );

    int likeCount =
            songMainService.getLikeLinkCount(
                    request.getOriginalLink()
            );

    return ResponseEntity.ok(likeCount);
}
```

 그러면 서버가 이런 식으로 응답합니다.

 좋아요 추가:

```
POST
↓
DB INSERT
↓
count = 4
↓
응답: 4
```

 좋아요 취소:

```
DELETE
↓
DB DELETE
↓
count = 3
↓
응답: 3
```

 # 3\. JavaScript에서 서버가 보내준 숫자를 사용

 기존에:

```
console.log("응답:", await response.text());
```

 라고 되어 있는데, 이걸 숫자를 받도록 변경합니다.

```
const newCount = await response.json();
```

 따라서 전체적으로:

```
const like_btn = document.querySelector(".like_btn");
const like_count = document.querySelector("#like_count");

like_btn.addEventListener("click", async () => {

    const originalLink = like_btn.dataset.originalLink;
    const is_liked = like_btn.classList.contains("active");

    const url = "/like-link/toggle-like";
    const method = is_liked ? "DELETE" : "POST";

    try {
        const csrfToken =
            document.querySelector('meta[name="_csrf"]').content;

        const csrfHeader =
            document.querySelector('meta[name="_csrf_header"]').content;

        const response = await fetch(url, {
            method: method,
            headers: {
                "Content-Type": "application/json",
                [csrfHeader]: csrfToken
            },
            body: JSON.stringify({
                originalLink: originalLink
            })
        });

        if (response.ok) {

            // 서버에서 계산한 실제 좋아요 개수
            const newCount = await response.json();

            // 좋아요 버튼 상태 변경
            if (is_liked) {
                like_btn.classList.remove("active");
                like_btn.textContent = "좋아요";
            } else {
                like_btn.classList.add("active");
                like_btn.textContent = "좋아요함";
            }

            // 좋아요 개수 변경
            like_count.textContent = newCount + "개";

        } else {
            alert("처리에 실패했습니다. HTTP 상태: " + response.status);
        }

    } catch (error) {
        console.error("네트워크 에러:", error);
    }
});
```

 HTML:

```
<h2 id="like_count"
    class="song_main_h2"
    th:text="${likeLinkCount} + '개'">
    0개
</h2>
```

 이 구조를 **추천합니다.**

 # 4\. 그런데 현재 코드에 한 가지 더 문제가 있습니다

 버튼을 처음 로딩할 때:

```
<button
    type="button"
    class="like_btn"
    th:data-original-link="${songMainEntity.songMainTitleId}">
    삭제하기
</button>
```

 이렇게 되어 있는데 버튼에는 처음부터:

```
삭제하기
```

 라고 되어 있습니다.

 그리고 JS에서는:

```
const is_liked = like_btn.classList.contains("active");
```

 를 사용합니다.

 그런데 처음 HTML에는:

```
class="like_btn"
```

 밖에 없습니다.

 즉 처음에는 무조건:

```
is_liked === false
```

 입니다.

 따라서 DB에 이미 이 사용자가 좋아요를 눌러놨어도 페이지를 새로고침하면:

```
DB: 좋아요 있음

화면:
class="like_btn"
is_liked = false
버튼 = 삭제하기
```

 상태가 됩니다.

 # 5\. 진짜 완성형으로 만들려면 `isLiked`도 서버에서 보내야 합니다

 서버에서 현재 로그인 사용자가 좋아요를 눌렀는지도 확인해야 합니다.

 예를 들어 Service:

```
public boolean isLiked(String originalLink, String userId) {

    return likeLinkRepository
            .existsByOriginalLinkAndLikeUserid_Userid(
                    originalLink,
                    userId
            );
}
```

 그리고 페이지를 렌더링하는 Controller에서:

```
boolean isLiked = likeLinkService.isLiked(
        songMainEntity.getSongMainTitleId(),
        principal.getName()
);

model.addAttribute("isLiked", isLiked);
```

 HTML:

```
<button
    type="button"
    class="like_btn"
    th:classappend="${isLiked} ? ' active' : ''"
    th:data-original-link="${songMainEntity.songMainTitleId}"
    th:text="${isLiked} ? '좋아요함' : '좋아요'">
    좋아요
</button>
```

 그러면 페이지를 새로고침해도:

```
DB
↓
현재 사용자가 좋아요 했는지 확인
↓
isLiked = true
↓
class="like_btn active"
↓
버튼 = 좋아요함
```

 으로 정확하게 유지됩니다.

 ## 정리

 현재 `likeLinkCount`가 안 바뀌는 이유는 **`countByOriginalLink()`가 잘못되어서가 아닙니다.**

```
public int getLikeLinkCount(String originalLink) {
    return likeLinkRepository.countByOriginalLink(originalLink);
}
```

 이 코드는 서버가 페이지를 처음 만들 때 정상적으로 실행됩니다.

 문제는 그 이후입니다.

```
Thymeleaf의 ${likeLinkCount}
        ↓
HTML로 변환됨
        ↓
브라우저에 표시
        ↓
AJAX로 DB 변경
        ↓
❌ Thymeleaf는 다시 실행되지 않음
```

 따라서 가장 추천하는 구조는:

```
① 페이지 최초 접속
   ↓
Thymeleaf
   ↓
현재 좋아요 개수 + 현재 사용자의 좋아요 여부 표시

② 좋아요 버튼 클릭
   ↓
POST / DELETE
   ↓
DB 변경
   ↓
Controller에서 countByOriginalLink()
   ↓
현재 좋아요 개수 JSON 반환
   ↓
JavaScript가 #like_count 변경
```

 입니다.

 그리고 **현재 상황에서는 `SongMainService`, `LikeLinkService`, `LikeLinkController`, 그리고 해당 페이지를 반환하는 `SongMainController`까지 연결해서 보면 훨씬 깔끔하게 정리할 수 있습니다.** 특히 `isLiked`를 추가하면 새로고침 후에도 버튼 상태까지 정확하게 유지할 수 있습니다.
